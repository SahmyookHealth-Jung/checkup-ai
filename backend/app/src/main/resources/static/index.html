여섯 단계 자세히
  1. 추출 (LLM) 결과지 PDF에서 항목·값·단위를 구조화 출력으로 뽑습니다
  2. 원문 대조 (코드) 뽑은 값이 원문에 없으면 버립니다
  3. 판정 (코드) 보건복지부 고시 판정기준표로 정상A·경계·질환의심을 정합니다
  4. 근거 조회 (코드) 항목 코드로 공개 문서 9편에서 근거 절을 찾습니다
  5. 해설 (LLM) 근거 절을 인용해 7개 항목의 문장을 씁니다. 10개 항목은 고정 문구입니다
  6. 검증·권고 (코드) 인용과 숫자를 근거와 대조하고, 위험 수치에 진료 권고와 고지를 붙입니다
