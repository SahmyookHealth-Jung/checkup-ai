포트폴리오 · 합성 데이터만 사용

건강검진 결과지를 읽고, 기준으로 판정하고,
공개 문서를 근거로 설명합니다

LLM은 결과지의 값을 베끼고, 근거가 있는 곳에서만 문장을 씁니다. 판정, 진료 권고, 고지, 받아들일지 여부는 코드가 정합니다. 어디에 LLM을 쓰고 어디에 쓰지 않을지는 측정으로 정했습니다. 진단은 하지 않습니다.

해설 데모 보기품질 수치운영 기록

처리 순서

1. 추출결과지 PDF → 항목·값·단위
LLM (Haiku 5.5), 구조화 출력
2. 원문 대조 검증원문에 없는 값은 받지 않음
코드
3. 기준 판정보건복지부 고시 판정기준표
코드
4. 근거 조회항목 코드로 공개 문서 절을 찾음
코드
5. 해설 문장근거를 인용한 문장만 남김
LLM + 인용·숫자 검증
6. 진료 권고·고지위험 수치는 진료 권고
코드

결과를 본 뒤 묻는 후속 질문은 항목으로 범위를 좁혀 근거를 찾고(글자 2-gram BM25), 진단·약 질문과 근거 없는 질문은 정해진 문구로 답하지 않습니다.

못 한 것과 한계

  • 후속 질문은 시험 통과 규칙을 채우지 못했습니다. 진단 질문 2건에 답했고, 진단 규칙을 더한 뒤에도 새 문항 8개 중 2개를 놓쳤습니다.
  • 결과지는 모두 합성 데이터입니다. 글자 층이 있는 PDF만 다루고 스캔 이미지는 다루지 않습니다.
  • 라벨러는 개발자 1명이고 의료인이 아닙니다. 채점기와 리뷰에 같은 계열 모델(Claude)이 많습니다.

기술

Java 21 · Spring Boot 4 · Spring AI 2 · PostgreSQL 18 + pgvector · Claude Haiku 5.5 · Ollama(bge-m3 임베딩, 오프라인 모드 qwen3:4b) · Python 평가 스크립트. 모든 LLM 호출은 토큰·비용·지연을 기록하고, 보내기 전에 식별정보를 지웁니다. 데모 호출은 하루 예산 상한을 지킵니다.
