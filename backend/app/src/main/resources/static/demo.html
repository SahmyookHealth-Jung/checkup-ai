결과지 해설받기

합성 결과지를 하나 고르거나 직접 만든 가상의 결과지를 올리면 추출 → 국가 기준 판정 → 근거 조회 → 출처 붙은 해설까지 돌립니다.

결과지를 올리기 전에 확인해 주세요 체험용 화면입니다. 실제 결과지 대신 직접 만든 가상의 결과지를 올려 주세요. 올린 파일의 글자는 해설을 만들기 위해 외부 AI 서비스(Anthropic Claude API)로 전송됩니다. 이름·주민등록번호·전화번호 같은 식별정보는 보내기 전에 지우지만 모두 걸러내지는 못하고, 검사 수치·성별·나이·검진일은 그대로 전송됩니다. 서버는 파일을 저장하지 않고, 추출한 내용만 후속 질문을 위해 잠시 메모리에 둡니다.
