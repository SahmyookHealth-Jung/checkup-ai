통계 질문

관리자가 한국어로 물으면 SQL로 바꿔 2023년 건강검진 표본 100만 명(국민건강보험공단 공공데이터)을 집계합니다. LLM이 쓴 SQL은 검사를 거쳐 읽기 전용 계정으로만 실행하고, 10명 미만 집단의 값은 숨깁니다.

SQL은 구조 검사(집계만, 허용 함수·테이블만)를 통과해야 실행되고, 숨김에 쓰는 인원은 서버가 직접 셉니다. 시험 40문항에서 실행 결과 일치 32/34(깨끗한 기준값 27/34), 막아야 할 요청을 실행한 건수 0. 자세한 기록은 품질에 있습니다.

합성 데이터로 만든 포트폴리오 데모입니다. 통계 데이터는 공공데이터포털 "국민건강보험공단_건강검진정보"(2023, 이용허락 제한 없음)입니다.
