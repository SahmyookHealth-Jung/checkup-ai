# 0009. 의미 충실도 채점기: 문장마다 호출하고, 3단계 라벨로 판정하며, thinking 설정은 보정셋에서 고른다

- 상태: 채택 (2026-11-11)
- 관련: ADR 0008 2절(채점 원칙)·4절 3번, devlog 2026-11-10 "5단계 2번, 기준선"

## 맥락

- 기준선(heldout 30개)은 형식 지표로는 거의 만점이었다. 문장 통과율은 0.99, 진료 권고는 73/73이었다.
- 하지만 통과한 873문장 중 81문장(9%)은 다른 항목의 기준표 행만 인용했다. 근거가 문장을 실제로 뒷받침하는지는 채점기로 재야 한다.
- ADR 0008이 정한 원칙은 아래와 같다. 이 ADR은 남은 구현 선택을 정한다.
  - 채점 모델: Sonnet 5.5
  - 채점 단위: 문장
  - 기준: 3축
  - 구절 확인: 채점기가 적은 구절이 청크에 있는지 코드가 본다
  - 보정: 사람 라벨 약 50문장으로 κ를 잰다
- 비용 추정의 근거(기준선 1회분)
  - 문장 436개, 항목 150개
  - 문장당 인용 근거는 평균 1.3개, 약 270자다
  - Sonnet 5.5 가격(100만 토큰당): 입력 $2, 출력 $10, 캐시 읽기 $0.10

## 결정 (사용자, 2026-11-11)

1. **호출 단위는 문장마다다.**
   - 보내는 것: 문장, 그 문장이 인용한 근거, 항목·결과값·판정 구간·판정 기준
   - 같은 항목의 다른 문장은 보내지 않는다. 문장끼리 판정에 영향을 주지 않게 하려는 것이다.
   - 채점 기준(시스템 프롬프트)은 프롬프트 캐싱으로 재사용한다.
   - 1회분은 약 $1.5로 추정한다(thinking 끔 기준).
2. **"근거가 뒷받침하는가" 축은 지지 / 부분 / 미지지 3단계다.**
   - 통과는 "지지"만이다.
   - 부분: 근거 있는 내용과 없는 내용이 섞인 문장(예: 기준 설명 뒤에 "생활습관을 점검하세요")
   - κ는 3단계와 2단계(지지 vs 나머지)로 둘 다 적는다.
   - 나머지 두 축의 라벨
     - 판정 구간: 맞음 / 틀림 / 말하지 않음
     - 치료·약 언급: 없음 / 있음
   - "뒷받침"은 **그 문장이 인용한 근거만** 보고 판단한다. 내용이 항목 정보와 맞아도 인용이 엉뚱하면 미지지다.
     - 사용자가 인용 번호를 눌러 확인하는 것은 근거 문단이기 때문이다.
     - 판정 구간 축은 항목 정보(결과값, 판정, 판정 기준)와 비교한다.
   - 정의는 `eval/rag/faithfulness_rubric.py` 한 곳에 두고, 라벨링 화면과 채점기가 함께 쓴다.
3. **보정셋 라벨링은 로컬 HTML 화면에서 한다.**
   - 화면 구성: 문장과 근거 원문을 나란히 보여 주고, 버튼으로 고른 뒤 라벨 JSON을 내려받는다. 서버는 없다.
   - 화면 파일에는 근거 원문(포털 글, 공공누리 제4유형)이 들어가므로 커밋하지 않는다. 라벨(문장 id + 판정 + 메모)만 커밋한다.
   - **사용자는 채점기 결과를 보기 전에 라벨링한다(눈가림).**
   - 50문장은 기준선 1회차에서 시드를 고정해 층별로 뽑는다.
     - 다른 항목 기준표만 인용한 문장 20개
     - 이웃 구간 위험이 있는 공복혈당·혈압 문장 10개
     - 나머지에서 무작위 20개
4. **thinking 설정은 보정셋에서 비교해 고른다.**
   - 비교할 두 조건은 "thinking 끔"과 "낮은 effort"다. 각각 50문장 × 3회를 채점한다.
   - 사람과의 일치도(κ), 자기 일치도, 비용을 보고 하나를 고른다. 고른 근거는 이 ADR의 결과 절에 적는다.

## 진행 순서

1. 보정셋 추출과 라벨링 화면을 만든다. 사용자가 라벨링한다.
2. 채점기를 구현한다. 라벨링과 동시에 할 수 있다. 사용자 라벨을 보지 않고 만든다.
3. 보정을 돌린다. 두 설정 × 50문장 × 3회다.
4. κ가 충분하면 기준선 2회분을 채점한다.

**비용 실측 (2026-11-11, 시험 호출 3문장 × 2설정):**
- 호출당 약 $0.006이다 (입력 약 500토큰, 캐시 읽기 약 2,000토큰, 출력 약 300토큰).
- 출력이 비용의 절반 이상이라 처음 추정보다 높다.
- 다시 추정한 비용
  - 보정: 약 $1.7
  - 기준선 1회분(436문장): 약 $2.5
  - 5단계 채점 전체: 약 $20

## 검토한 대안

- **항목마다 한 번 호출:** 캐싱을 쓰면 1회분 $0.3 정도 싸다. 하지만 앞 문장이 뒤 문장 판정에 영향을 줄 수 있고, ADR 0008의 "문장 단위"와도 어긋난다.
- **지지 / 미지지 2단계:** 라벨링이 빠르고 κ가 높게 나오기 쉽다. 하지만 섞인 문장의 처리가 매번 흔들리고, 개선 후 "부분 → 지지" 변화가 보이지 않는다.
- **CSV·스프레드시트 라벨링:** 만들 것은 가장 적다. 하지만 긴 근거 원문을 셀에서 읽기 어렵고, 입력 오류를 나중에 걸러야 한다.
- **thinking 기본값(켬, effort high):** 판단이 가장 꼼꼼할 수 있다. 하지만 5단계 채점 전체가 $30을 넘을 수 있고, 근거 없이 정하게 된다.
